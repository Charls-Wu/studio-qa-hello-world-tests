# Independent QA working directory

This repository contains the test standard, scripts, and evidence for the Hello World application.
Use Node.js built-ins. Read `checks/hello-world.json` before testing.
Only version a new expected output when the linked Studio requirement explicitly authorizes the change.
Test the exact application commit or branch, not a copy of the source.
Keep analysis, standard version changes, script changes, execution results and human acceptance distinct.
No application code changes in this repository. Leave acceptance to the owner.
